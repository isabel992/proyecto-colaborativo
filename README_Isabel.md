## Comandos Utilizados en Git
### `git init`
Inicializa un nuevo repositorio Git en el directorio actual.
### `git commit -m "mensaje"`
Realiza un commit con un mensaje descriptivo, guardando los cambios en el historial del proyecto.
### `git clone <url del repositorio>`
Clona un repositorio remoto a tu máquina local, descargando todo su contenido y su historial.
### `git checkout -b <nombre-de-rama>`
Crea y cambia a una nueva rama para trabajar en una nueva funcionalidad o corrección.
### `git checkout main`
Cambia a la rama principal para trabajar en el código estable o fusionar cambios.
### `git .add`
Agregar los cambios al área de preparación.
### `git push origin <nombre-de-rama>`
Para subir la rama a Git Hub de la rama.
### `git push origin main`
Subir los cambios a Git Hub del main.
### `git pull origin main`
Coge la última versión de main desde GitHub.
### `git merge <nombre-de-rama>`
Fusionar la rama con el main.
