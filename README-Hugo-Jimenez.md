# Proyecto-Colaborativo

Este es un proyecto colaborativo que tiene como objetivo principal mejorar y optimizar el diseño y la funcionalidad de una interfaz web utilizando **Hugo** y **CSS**.

## Hugo JB - Parte CSS

En este proyecto, se están aplicando tecnologías como Hugo para la generación estática de sitios web y CSS para el diseño de la interfaz de usuario. Se busca crear una experiencia visualmente atractiva y altamente funcional.

## Problemas encontrados

Al cambiar de ordenador (de clase a casa o viceversa), es necesario volver a configurar la interfaz de git
